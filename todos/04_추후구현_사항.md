# 추후 구현 사항 (중장기)

> 기준 문서: 피그마 기획서 대비 앱 구현 현황 비교 분석 보고서 (2026.03.22)
> 현재 즉시 수정이 아닌, 데이터 확보 또는 협력 업체 연동 후 구현할 항목들

---

## 1. 우리 아이 체급 계산기 (미니 기능)

- [ ] 매장 썸네일에서 입장 가능 여부 판단용 체급 계산기 구현
- [ ] 체급 분류 기준:

| 분류 | 몸무게 기준 | 대표 견종 | 특징 |
|------|-----------|----------|------|
| 소형견 (Small) | 7kg 미만 | 말티즈, 포메라니안, 토이푸들, 치와와 | 대부분의 실내 카페 출입 가능 |
| 중형견 (Medium) | 7kg ~ 15kg | 프렌치 불독, 시바견, 코기, 비글 | '소형견 전용'에서 거절당할 확률 높음 |
| 대형견 (Large) | 15kg 이상 | 리트리버, 사모예드, 허스키, 도베르만 | 전용 운동장이나 대형견 허용 시설 필요 |

## 2. 매장 상세 - 이미지 5장 확보

- [ ] 카테고리별 5가지 항목 이미지 데이터 확보
- [ ] 각 소 카테고리에 맞는 고유 이미지 항목 정의 (중복 방지)

## 3. 매장 상세 - 반려견 동반 조건

- [ ] 제한 사항 데이터 확보 및 항목 추가

## 4. 매장 상세 - 장소 정보 추가 항목

- [ ] 주차 가능 여부 데이터 확보 및 노출
- [ ] 편의 시설 데이터 확보 및 노출
- [ ] 특이 사항 데이터 확보 및 노출

## 5. 매장 상세 - 이용시 주의사항

- [ ] 펫티켓과 별도로 이용시 주의사항 영역 추가 구현

## 6. 매장 상세 - 댕댕이들의 방문기

- [ ] 매장 키워드 기반 API 연동
- [ ] 방문기 정보 노출 구현

## 7. 핫플레이스 - 장소 주차장 마커

- [ ] 장소 주차장 위치 마커 구현

## 8. 핫플레이스 - 협력 업체 투어 일정 (대규모)

- [ ] AI펫닥터 추천 투어 일정 구현
- [ ] 투어 장소 주변 추천지 노출
- [ ] AI펫닥터 추천 투어 시 주의사항 노출
- [ ] 해당 투어 장소 지도로 확인하기 기능
- [ ] 투어 일정 상세보기 페이지
- [ ] 협력업체 이벤트 페이지 이동 버튼
- [ ] 티켓 예약하기 기능
