# 매장 상세 페이지 수정사항

> 기준 문서: 피그마 기획서 대비 앱 구현 현황 비교 분석 보고서 (2026.03.22)

---

## 1. 매장 이미지 노출 (논의 필요)

- [ ] **[논의]** 카테고리별 5장 이미지 항목 재분류 필요
  - 현재 동물병원과 동물약국의 이미지 항목이 동일하게 설정되어 있음 (병원인데 약국 내부가 노출되는 문제)
  - 각 소 카테고리에 맞는 고유한 5장 이미지 항목 정의 필요
- [ ] **[당장 조치]** 이미지 데이터 확보 전까지 썸네일 이미지 1장으로 대체 노출
- [ ] **[추후]** 카테고리별 5가지 항목 이미지 확보

## 2. 상호 영역 수정

- [ ] "주차가능" 항목 삭제 (데이터 미확보)
- [ ] 해시태그를 업종, 허용공간 기준으로 통일

## 3. 갱신정보 위치 변경

- [ ] 갱신정보를 매장 위치 아래 → **상단 첫줄**로 이동 (최신 정보 중요성 반영)

## 4. 반려견 동반 조건

- [ ] 동반방법, 허용공간은 현재 노출 중 — 유지
- [ ] **[추후]** 제한 사항 항목 추가

## 5. 장소 정보 6개 항목 동일 노출

- [ ] DB에 있는 6개 항목 동일하게 노출 확인:
  - 주소
  - 지번
  - 전화번호
  - 영업시간
  - 휴무일
  - 전화
- [ ] **[추후]** 주차 가능 여부 추가
- [ ] **[추후]** 편의 시설 추가
- [ ] **[추후]** 특이 사항 추가

## 6. 펫티켓 교체

- [ ] "이용시 주의사항" 영역을 **펫티켓 5가지 항목**으로 교체
- [ ] **[추후]** 이용시 주의사항은 별도 영역으로 추가 구현

## 7. 매장 위치 지도

- [ ] 미니 지도 이미지 노출 구현 (현재 카카오맵 연동만 있음)

## 8. 방문 후기 및 정보 수정 레이아웃 재배치

- [ ] 정보 갱신일을 매장 위치 아래 → **상단으로 이동**
- [ ] 리뷰(블로그 후기)를 매장 위치 아래에 노출
- [ ] 정보 수정 요청 버튼을 눈에 띄는 **카드 형태**로 수정

## 9. 주변 유사 매장 정보

- [ ] 매장 이미지 노출 추가 (현재 상호, 업종, 거리만 노출 중)

## 10. 댕댕이들의 방문기

- [ ] **[추후]** 매장 키워드 기반 API를 통한 방문기 정보 노출 구현
