# 펫세권 수정사항

> 기준 문서: 피그마 기획서 대비 앱 구현 현황 비교 분석 보고서 (2026.03.22)

---

## 1. 하단바 카테고리 재분류

- [ ] "놀이/쇼핑" 카테고리를 **펫용품, 운동장, 쇼핑** 3개로 분리 노출
- [ ] "용품판매" 카테고리 삭제
- [ ] 하단바 아이콘 트렌디하게 변경 (디자인 작업 필요)

## 2. 하단바 소 카테고리 중복 클릭 버그 수정

- [ ] 소 카테고리 이중 클릭 가능하게 구현 (다중 선택)
- [ ] 소 카테고리 재클릭 시 해지(선택 해제) 가능하게 구현

## 3. DB 데이터 누락 보완

- [ ] 동물장묘업 데이터 DB에 추가
- [ ] 용품판매 데이터를 아래 2개로 분리하여 재등록:
  - **쇼핑**: 반려동물과 함께 쇼핑할 수 있는 장소
  - **펫용품**: 반려동물에게 필요한 물건을 구매하는 장소

## 4. 매장 썸네일 이미지 노출

- [ ] 장소 썸네일용 이미지 사진 데이터 추출
- [ ] 공유 버튼 아이콘 교체
- [ ] 썸네일 항목을 기획서와 동일하게 반영

## 5. 디자인

- [ ] 펫세권 전체 디자인 컬러 민트 톤 적용 확인
